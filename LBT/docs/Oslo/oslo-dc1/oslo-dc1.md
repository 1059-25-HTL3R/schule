## DNS

### Reverse Lookup Zone erstellen

Im DNS editor:

- Reverse Lookup Zone erstellen:
- Primary Zone (default)
- only in this domain (default)
- IPv4 Reverse Lookup Zone (default)
- 10.3.3. als Network
- only secure updates from domain (default)

dann in den records der forward lookup zone, den tick "update ptr record" auswählen (ggf. nochmals) -> für namesauflösung von IPs
